## What's new in 0.3.3

**Renaming a column keeps things working.** When you rename a column, data check rules that name it, such as `[first_name] <> ""`, change to the new name too, and Ctrl+Z puts both back. If another column already has that name, the rules name the column by its number instead (`[#2]`) so they keep testing the same column, and the status line says so. A column with no name, which rules call `[Column 3]`, is followed too. A rename is now a recipe step, so a recipe recorded across it replays the rename before the steps that use the new name. A saved pivot layout or saved view that names a column this file no longer has (because it was renamed) now asks whether to use the column in the same place, and lists which one, instead of refusing (pivot layouts) or switching silently (views). A view's data check rules follow the columns it ends up using.

Everything from 0.3.2 is included: Rename column, smoother tab dragging, and right-click picking what it is on.

## Install

1. Download `Natendo.Data.Edit_0.3.3_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
