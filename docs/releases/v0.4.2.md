## What's new in 0.4.2

**Formulas where you work.** Type a formula straight into a cell, filter or rewrite a column with one, and twenty more functions:

- **Formulas in cells.** Type `=B2*C2`, `=SUM(C2:C40)`, `=SUM(C:C)` or `=[Price]*[Qty]` in a cell and press Enter: the formula runs once and the cell keeps the result (a CSV file holds values, not formulas). Columns go by letter, rows by the number in the row heading. Select a block and press Ctrl+Enter to fill it, with references moving row by row as in a spreadsheet (`$C$2` stays put), so `=SUM($C$2:C2)` fills a running total. A long fill shows its progress and can be cancelled. F2 and the cell bar show the formula again until the cell changes. Start with an apostrophe (`'=`) to keep text that begins with "=".
- **Formula helper.** While you type a formula, in a cell or in the formula screens, functions that fit are suggested (Tab puts one in) and a line shows how the function you are in is used.
- **Filter by formula** (Data › Filter by formula). Show only the rows where an expression is TRUE, like `AND([Total] > 100, ISBLANK([Notes]))`, with the first results shown as you type.
- **Change a column with a formula** (Data › Change column with a formula, or right-click a heading). Rewrite a column in place, like `UPPER([Name])` or `PADLEFT([ZIP], 5)`, in one undo step. Only shown rows change, and a cell where the formula gives an error keeps its value.
- **Twenty new functions.** Dates: AGE, DATEDIF, EDATE, EOMONTH, NETWORKDAYS, WEEKNUM, DATEVALUE. Text: TEXT, TEXTBEFORE, TEXTAFTER, SPLITPART, PADLEFT, CLEAN, COUNTCHAR. Choices: SWITCH, CHOOSE, IN, BETWEEN. The rows around: PREV and NEXT (the value in the row above or below, as shown). Also COUNT and COUNTA.

Every one of them was timed on a 10-million-row file and stays within the app's speed budgets.

## Install

1. Download `Natendo.Data.Edit_0.4.2_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
