## What's new in 0.3.4

**Column lists start with nothing ticked.** Every screen where you tick columns, such as Show duplicates, Remove duplicates, Merge rows, Subtotals, Group figures, Fill blank cells, Join, Match, Updates, Notes, street addresses and the chart panel, now starts with no columns ticked. Each has **Select all** and **Unselect all** buttons above the list. Screens that need at least one column ask for one; on the duplicates screens, ticking none still compares whole rows, as the screen says.

**Undo covers far more.** Ctrl+Z and Ctrl+Y now take back and redo filters (Filter, Filter by selected value, Show duplicates, showing rows with problems or notes, and Clear filter), column widths and AutoFit, hiding and showing columns, display formats, wrapping, row height, highlight rules, colour scales, banding, the group line and data checks, all in the order you did them along with your edits. Undoing a column delete brings the column back at its width. Filters and the look of the table don't count as unsaved changes, so they never stop you closing a file.

**The active cell stays where you started**, as in Excel and Google Sheets. After Shift+arrows, Ctrl+Shift+arrows, Shift+click, Shift+Space or Ctrl+Space, typing goes into the cell you started from, and a plain arrow key moves on from there (Ctrl+Shift+Down then Down lands one row below where you started, not at the bottom).

Everything from 0.3.3 is included: renaming a column keeps data check rules, saved pivot layouts and saved views working.

## Install

1. Download `Natendo.Data.Edit_0.3.4_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
