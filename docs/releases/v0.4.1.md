## What's new in 0.4.1

**Quick wins for daily work.** Eight small tools that people who work with data every day reach for again and again:

- **Show invisible characters** (View › Show invisible characters, Ctrl+Shift+H). Spaces show as a faint dot, tabs as an arrow and line breaks as ⏎; non-breaking, zero-width and other odd spaces show in orange, the usual reason two names that look the same won't match. A line under the cell bar names what the cell holds that can't be seen. Display only.
- **Go to special** (Edit › Go to special, Ctrl+Shift+G). Pick the blank cells, the cells with numbers or text, the cells that differ from another column in their row, the cells changed since the file was opened or saved, or the cells that fail a data check. Then light them up, fill them all with one value ("fill every blank in these three columns with UNKNOWN") or clear them, in one undo step.
- **Pick up where you left off.** At start, the app offers to reopen the files that were open last time, each at the same cell with its filter, hidden columns and widths. Only where each file is and how it was shown are kept, never what is in the cells; private-mode and encrypted files are never remembered. File › Options can make it reopen without asking, or never remember.
- **Zipped and gzipped files.** Open `voters.csv.gz` or `export.zip` without unpacking them first; a zip with several tables lists them to pick from. Everything is unpacked in memory only. A `.gz` file saves back gzipped; a table from a zip opens as a new tab (the zip is never changed).
- **JSON Lines** export (`.jsonl`): one record per line, as web tools and databases use. (Opening them already worked.)
- **Protect columns** (right-click a heading › Protect column). Typing, paste, fill, Replace, cleaning tools and every other change pass a protected column over and say how many cells they left; sorting, filtering and renaming still work. A padlock shows in the heading, and views keep it.
- **Tidy column titles** (Format › Tidy column titles). Trim and collapse spaces, one case style (Title Case, lower_with_underscores, UPPER), remove odd characters, and make repeated titles unique (Phone, Phone 2), with a preview first.
- **Compare two columns** (Data › Compare two columns). For each row: same, different, or only one filled? Light up the rows that differ, show only them, or add a column saying which. Case, extra spaces and numbers of equal value count as the same unless you say otherwise.

Every one of them was timed on a 10-million-row file and stays within the app's speed budgets.

## Install

1. Download `Natendo.Data.Edit_0.4.1_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
