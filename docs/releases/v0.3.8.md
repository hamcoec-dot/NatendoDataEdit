## What's new in 0.3.8

**Paste into filtered rows, safely.** While a filter is on or rows are hidden, Paste, Paste Special, fill, Ctrl+Enter, Delete and Copy already worked on the rows you can see. Two edges are now safe too:

- **A paste taller than the rows showing** used to put the extra rows quietly at the very end of the file. Now Natendo asks first, with the real numbers: fill the shown rows and stop (the main button), fill them and add the rest as new rows at the end (they are selected afterwards so you can see them), or cancel. No choice ever writes over a hidden row. Paste Special asks the same question.
- **Hidden columns are passed over.** A paste skips hidden columns and goes on in the next shown one. Clear, Ctrl+Enter and fill leave hidden columns alone, and Copy leaves them out, so a hidden ID or birth date column is never overwritten or sent to the clipboard.

**The status line says what happened**: "Pasted 120 rows into the shown rows only. 3,412 hidden rows between them were left as they were." The same goes for fill and clear.

Every one of these is still one Ctrl+Z.

## Install

1. Download `Natendo.Data.Edit_0.3.8_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
