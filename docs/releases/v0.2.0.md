## What's new in 0.2.0

**Pivot tables, rebuilt.** Data > Pivot table now opens a drag-and-drop builder like the one in Excel:

- Drag fields into Rows, Columns, Values and Filters; the result updates as you go.
- Count, distinct count, sum, average, smallest, largest, median and more, in any combination.
- Group dates by year, quarter, month, day, weekday or hour, and numbers into ranges.
- Top N, label and value filters, subtotals and grand totals, "show values as" (% of grand, column, row or parent total, running total, rank and more).
- Double-click any number to see the rows behind it.
- Save a layout and open it again later; open the result as a new tab or copy it.
- Works on 10-million-row files, with a memory limit so it never takes over your PC.

**Command search as a feature launcher (Alt+Q).** Type a few letters or everyday words ("dedupe", "vlookup", "trim") and every matching tool shows at once, with the menu it lives in and what it does. Enter opens it.

Plus review fixes and speed work throughout.

## Install

1. Download `Natendo.Data.Edit_0.2.0_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
