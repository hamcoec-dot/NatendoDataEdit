## What's new in 0.3.6

**Menus show where the mouse is.** In the menu bar and in every right-click menu (cells, rows, columns, file tabs), the item under the pointer now gets a light highlight, in the light and dark themes. A right-click menu opens with nothing picked; Shift+F10 or the Menu key starts on the first item, ready for the arrow keys.

**Find and Replace keep to your selection.** With several cells selected, Find and Replace now remember that block: Find next moves through it (the block stays selected), and Replace all changes only the cells inside it. In 0.3.5, after the first Find next the search could quietly go on through the whole file, so Replace all could change cells outside the selection.

**Ctrl+A finds the block in one go.** The block of data around the cell is now found by one quick look at the file, across every column, as Excel does. The header row is never part of it.

**Undo of a sort or tool leaves the selection alone.** Undoing a sort, filter or cleaning tool says what it undid but no longer jumps to wherever the selection was when the tool ran. Undoing a fill, paste, clear or move still selects those cells.

**Help › Mouse and drag moves** now lists the newer mouse moves: the column menu arrow on headings, double-clicking the selection's edge, dragging the fill handle back to clear, the file tab menu, and more.

**Changed key.** Since 0.3.5, Ctrl+Shift+PageUp and Ctrl+Shift+PageDown switch between files (as in Google Sheets). Moving a file tab from the keyboard is now Ctrl+Alt+Shift+PageUp and Ctrl+Alt+Shift+PageDown.

## Install

1. Download `Natendo.Data.Edit_0.3.6_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
