## What's new in 0.5.0

- **Find and Replace in several blocks.** Select blocks with Ctrl+click, press Ctrl+F or Ctrl+H, and Find looks in all of them and nowhere else: "Selection (3 blocks, 33 cells)". Find next and Find previous go through the matches row by row across the blocks, wrap round, and keep every block selected; the count, the lit-up matches, Find all and its row actions, Replace and Replace all work on the same cells. A cell that is in two blocks is searched and replaced once, and one Ctrl+Z undoes a Replace all. If the rows shown change while Find is open (a filter, hidden rows, a sort), the blocks are let go with a message.
- **Enter and Tab between blocks.** With several blocks selected, Tab moves along each row of the active block and Enter down each column, then on to the next block in the order you picked them, as in Excel. Shift goes back.
- **Select several blocks at once.** Ctrl+click adds a cell, Ctrl+drag adds a block, and Ctrl+click on a column heading or row number adds the whole column or row. The status bar totals cover every block. Delete, Ctrl+Enter, pasting one value, Copy (when the blocks line up), alignment, wrap and number formats work on all of them; anything that needs one block says so and changes nothing.
- **Row heights.** Drag the line under a row number to make that row taller or shorter, or type an exact height or fit a row to its wrapped text (Format menu and the row right-click menu). Heights follow their rows when rows are inserted, deleted or moved, come back with Undo and Redo, are kept in saved views and "Pick up where you left off", and are written to Excel files you export.
- **A tab in its own window.** Right-click a tab and choose Move tab to a new window to see two files side by side, on two screens if you like. Both windows share the open files and their undo history, and Move tab back to the main window returns it.
- **Drag cells onto another tab.** Select a block, drag its outline onto another tab's heading and the block is copied there (Shift moves it).
- **Group look-alike values** by sound or by spelling in the value editor ("Main St" and "Main Street", "Jon Smyth" and "John Smith"), with common names never joined to each other.
- Faster to check: the speed tests the maker runs now cover Find over many blocks and are sized correctly for smaller files.

## Install

1. Download `Natendo.Data.Edit_0.5.0_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
