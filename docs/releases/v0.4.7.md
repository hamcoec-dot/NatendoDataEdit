## What's new in 0.4.7

- **The app asks about the title row.** The first time a file opens, a bar above the table says whether the first row looks like column names and asks if that's right: Yes or No, or ignore it and keep the guess, which is already applied. Your answer is remembered for that file, so it asks only once; if you ignore the bar, the guess is kept when the file closes. Answering from the keyboard works too: Alt+Shift+Y or Alt+Shift+N. Once answered, the bar says what was kept and stays put, so the table doesn't jump under the mouse. Files in private mode are not asked. The guess is smarter too: it is sure when text names sit over numbers or dates, or when every name is a column word such as "id" or "first_name". Format > Ask about the title row when a file opens (also in Options) turns the question off, and Format > Ask about the title row again (also on the heading right-click menu) brings it back.
- **No more "reopen last time's files?" for a file you just opened.** When you open a file from Windows and that starts the app, it no longer offers to reopen that same file. Other files from last time are still offered, and after they reopen the file you double-clicked stays in front.

Opening a file costs nothing extra you can notice: the guess reads only the first 20 rows, as before.

## Install

1. Download `Natendo.Data.Edit_0.4.7_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
