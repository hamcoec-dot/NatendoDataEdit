## What's new in 0.4.5

**Share well, and see two places at once.**

- **Excel files made for Excel users** (File › Export, Excel). The title row is bold, stays in view and has filter buttons. Columns are as wide as their values, or as you set them on screen. Dates, money and percents become real Excel values with their formats, so they sort and add up. IDs, ZIP codes and phone numbers stay text, so leading zeros survive and Excel shows no "number stored as text" warnings. No author or other personal details go in the file. Checked in Excel itself, and 1 million rows export in under a second.
- **More rows than Excel holds.** A table longer than an Excel sheet (1,048,575 rows under the titles) is cut into parts automatically, each with the title row: as separate files ("voters (1 of 10).xlsx") or as sheets of one workbook. The app remembers your choice, and you can set your own rows per part. For very large tables, separate files are easier for Excel to open, and the window says so.
- **All open tabs as one workbook**, each on a sheet named after its tab.
- **Audit samples** (Tools › Random sample). Draw a number or a percent of rows from each group of a column ("10 ballots per precinct"), with a seed number that is shown and kept. The same seed draws the same rows of the same table again, so anyone can check the sample. A record opens beside it with the seed, the method (published in the README so others can reproduce it), the file's SHA-256 fingerprint and the rows in and taken per group.
- **Split view** (View › Split top and bottom, Alt+Shift+W, or Split side by side). Two panes of the same tab, each scrolling on its own: copy from row 3 to row 1,800,000, or compare rows far apart. Drag the bar to resize it, or to the edge to close it.
- **Refresh a pivot table** (Data › Refresh pivot table, Alt+F5, or right-click the pivot's tab). It builds the pivot again from its source after edits there, in the same tab.

Timed on a 10-million-row file: every row to Excel in 10 files of parts in 6.9 s (1 million rows in 0.7 s, five times faster than 0.4.4), and an audit sample of 10 rows from each of 311 groups in 0.33 s. Split view and Refresh cost nothing until used.

## Install

1. Download `Natendo.Data.Edit_0.4.5_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
