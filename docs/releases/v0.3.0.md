## What's new in 0.3.0

**Drag to move and arrange, as in Google Sheets.**

- Select columns and drag them by their headings to put them somewhere else. A see-through band follows the pointer and a bar shows where they will land. Rows work the same way by their numbers.
- Drag a selected block of cells by its outline to move it. Hold Ctrl to copy it instead. Esc stops a drag.
- Column widths, display formats, wrapping, colour scales, highlight rules and checks move with their columns, and Ctrl+Z puts everything back in one step.

**Cut and paste that moves.** Ctrl+X marks whole columns, whole rows or a block of cells with a dashed outline and changes nothing yet. Click where they should go and press Ctrl+V: columns go in before the column you picked, rows above the row you picked, and the gap they leave closes up. There is no empty column to insert or delete by hand. Esc cancels. The right-click menus of cells, row numbers and column headings have Cut, Copy, Paste, "Move what was cut here" and "Cancel cut".

**More mouse moves:**

- Resize or double-click-fit several selected columns at once.
- Click the small arrow beside hidden columns to show them again, at their old width.
- Drag the bottom or right edge of the top-left corner to freeze rows or columns.
- Drag file tabs into another order.
- Help > Mouse and drag moves lists every one; the Ctrl+/ shortcuts list has a Mouse section too.

**Fixed:**

- Pressing Alt+Q a second time now closes the search box, as it should. On some PCs Windows sent the second press without saying Alt was held. The same fix makes the Alt+letter menu keys reliable.
- Hiding a whole column no longer jumps the view to the last row.

## Install

1. Download `Natendo.Data.Edit_0.3.0_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
