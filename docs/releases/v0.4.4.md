## What's new in 0.4.4

**Repeat your work without thinking.** Recipes become something to trust for the monthly job:

- **Recipe steps panel** (View › Recipe steps, Alt+Shift+R). The steps you take on a tab are listed as you work, like Power Query's applied steps. Click one to see the table as it was after it, then go back to the latest; while you look back, changes and saving are off, so the later steps are never lost. Turn a step off, move it, take it out or change its settings, and the steps after it run again (buttons, or right-click a step). If a step then fails, or you cancel, everything is put back as it was. If going back would undo a paste or changes typed by hand, it asks first.
- **Recipe questions.** Press ? on a step to have the recipe ask for one of its values each time it runs ("Which county?"), with the last answer filled in. One recipe then serves every county or every election. On the command line: `natendo-cli run monthly.recipe.json in.csv -o out.csv --set county=Knox`.
- **Run recipe on files** (Tools › Run recipe on files). Pick files or a folder, a recipe and a results folder: every file is run now and written under its own name, with a line for each file (rows in, rows out, or why it was not done) and a total. The files picked are never changed, and when the results folder already holds files of those names it asks first: replace them, or keep them and add (2) to the new names.
- **Command-line toolkit.** New `natendo-cli` commands for scripts: `headers`, `select`, `filter`, `sort`, `dedupe`, `stats`, `count`, `sample`, `slice`, `split` and `cat`, each with `--json`. Columns go by title or by number.

Looking back at a step and forward again is undo and redo, so it is as quick as Ctrl+Z, even on a 10-million-row file. On the same file, `natendo-cli filter` keeps a filter's rows in under 2 seconds.

## Install

1. Download `Natendo.Data.Edit_0.4.4_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
