## What's new in 0.3.1

**Open recent files at any time.** File > Open recent (Ctrl+Shift+O) shows the same recent files as the start page, even when files are already open. Tick two or three of them and each opens in its own tab, double-click one to open it straight away, or middle-click files one after another: each opens in a new tab and the list stays open. Middle-clicking a file on the start page opens it and brings up the same list, so you can keep going. Up and Down move through the list and Enter opens. Files that are already open are marked "open" and are switched to instead of being opened a second time, and two files with the same name (say, 2024\Data\voters.csv and 2025\Data\voters.csv) show the folder that tells them apart, in the list and on their tabs (only that folder, never the whole path). Alt+Q finds it too: type "recent".

Everything from 0.3.0 is included: drag to move columns, rows and cells; cut and paste that moves; more mouse moves; and the Alt+Q fix.

## Install

1. Download `Natendo.Data.Edit_0.3.1_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
