## What's new in 0.6.0

### See problems in your data

- **X-ray gremlins** (Ctrl+Shift+X) makes smart quotes, odd spaces, tabs and breaks inside cells, and look-alike letters (a Cyrillic "а" hiding in a Latin word) glow. A report counts them by kind and column, and **Sanitize selection** fixes the ticked kinds with a preview, in one undo step. Switching X-ray on or off redraws the table at once.
- **Pattern pill:** the column insight strip shows the usual shape of a column (such as `999-9999`) and the share that differs. Click it to see only the rows that break it.
- **Data checks with names:** several rules per column, ready-made rules and suggestions from your data, a wavy underline, **F7** / **Shift+F7** to jump between problems, and rules that can be kept beside the file.
- **Compare two files by key:** rows are paired by the columns you pick and columns by their titles. Differences are coloured in both files and in a result tab, and **Alt+F7** jumps between them.

### Change data safely

- **Ghost diff:** the cells on screen show what Replace all would write, before you press it.
- **Checkpoints** (Ctrl+Alt+K): name how the table looks now and come back to it in one jump. The app names one itself before risky changes such as Replace all or removing duplicates.
- **What changed since a checkpoint:** counts first, then the changed cells (was and now), the rows and columns taken out, and the new rows, with a CSV report.
- **Record panel** (Alt+R): the current row as a list of fields beside the table, with search, pinned fields and editing in place.

### Read files correctly

- **Column types:** say that a column is Text, Number, Date or Id. An Id such as a ZIP code is never added up or sorted as a number, and `007` stays different from `7`. The file itself does not change.
- **Change encoding:** read a file as UTF-8, Windows-1252, UTF-16, UTF-32, Shift_JIS, GBK or Big5, previewing with the arrow keys; find rows written in another encoding; and repair double-encoded text such as `cafÃ©` with **Fix mojibake**.
- **Imports keep numbers as written:** long ID numbers from spreadsheets and JSON are no longer rounded, and leading zeros shown by an Excel sheet can be kept.

### Also

- The window stays responsive while a long job runs on a large file.
- Large JSON files open a little faster.

### Known limit

- In a LibreOffice `.ods` sheet, a leading-zero number format is not applied yet: the number comes in without the zeros it was shown with.

## Install

1. Download `Natendo.Data.Edit_0.6.0_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
