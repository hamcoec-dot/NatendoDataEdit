## What's new in 0.5.1

- **Security updates to two libraries.** The web-address library (`url`, 2.5.9) and the cookie library (`cookie`, 0.18.3) that the app's window framework uses were updated to versions that fix two newly published problems (RUSTSEC-2026-0592 and RUSTSEC-2026-0594). Neither could be reached through anything Natendo Data Edit does, but the fixed versions are the ones to be on.
- **Checked on a million rows.** Exporting a million-row file to Excel in parts takes the same time after a long working session (sort, filter, Find all, undo) as on a fresh start: 0.41 s fresh and 0.46 s after, here.
- Behind the scenes: the speed tests the maker runs are now sized for the file they run on, so a smaller test file is no longer held to a budget meant for a bigger one.

## Install

1. Download `Natendo.Data.Edit_0.5.1_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
