## What's new in 0.3.5

Natendo Data Edit now works much more like Excel and Google Sheets: how typing moves, how cells look, the keys, the menus and the status bar.

**Typing moves like Excel.** After typing in a cell, an arrow key keeps what you typed and moves to the next cell. F2 (or a double-click) edits inside the text instead, where the arrows move the caret, and F2 switches between the two.

**Enter and Tab move through a selected block.** With several cells selected, Enter moves down and Tab moves right inside the block, wrapping at its edges, and the block stays selected, so you can type a block of values in. Tab, Tab, Enter goes to the next row in the column you started from.

**Insert and delete cells.** Ctrl+Plus or Ctrl+Minus on part of a row now asks what to do: shift the other cells (right or down when inserting, left or up when deleting), or take the entire rows or columns. Before, it deleted whole rows without asking. The box warns that shifting cells moves values into other rows or columns, and asks again before shifting more than 1,000 rows. Whole rows or columns selected still go straight away, and the cell right-click menu has Insert cells… and Delete cells….

**Clear or fill big selections.** Delete and Ctrl+Enter no longer stop at 100,000 cells: they work on up to 5 million cells, with a progress bar and Cancel, and whole columns down to the last row (with no filter on) clear at once, however many rows there are. List of my changes shows such a column as cleared. Undo takes it all back.

**Clicking a column or row heading** makes its top (or first) cell the active one, so typing goes there.

**It looks like a spreadsheet.** Numbers and dates sit on the right (View › Numbers on the right turns it off), and Format › Align left, center, right or automatically sets any column. Long text spills into the empty cells beside it instead of being cut off; Format › Cut off long text keeps a column's text inside it. View › Column letters adds A, B, C to the headings. A small arrow marks the column the rows are sorted by.

**Status bar: Sum and Count together.** Select cells and the status bar shows Sum and Count side by side (just Count when there are no numbers). Click it to tick Average, Min, Max and the others too, or to copy one.

**Undo and Redo show what they did.** They select the cells that changed and say what was undone or redone ("Undid typing in R9 C3", "Undid “Paste”").

**Copy and paste like Excel.** Copied cells get a dashed outline (Esc removes it), and a copied block pasted into a bigger selection that it fits a whole number of times repeats to fill it.

**Go To understands more.** The name box takes "250", "R250 C3", Excel's "F250" or a column title ("city 250"). While a filter is on, it finds rows by the numbers shown on screen, and the name box shows them too.

**More Excel and Google Sheets keys.** Shift+F10 or the Menu key opens the right-click menu. Ctrl+1 opens Display format; Ctrl+Shift+1, 3, 4 and 5 show columns as number, date, currency or percent; Ctrl+\ removes the format. Ctrl+' starts an edit with the value above. Ctrl+; and Ctrl+Shift+; now start an edit with the date or time, so you can add to it or press Esc. Ctrl+A selects the block of data around the cell first and everything on the second press (Ctrl+Shift+* selects the block). Ctrl+Backspace, Shift+Backspace, Ctrl+., F8 (extend mode), Alt+PageDown/PageUp (a screen sideways), Space on a tick box, Alt+/ for command search, Ctrl+Shift+PageDown/PageUp to switch tabs (moving tabs is now Ctrl+Alt+Shift+PageDown/PageUp). Esc no longer shrinks the selection. Home, End and Ctrl+arrows skip hidden columns.

**Mouse and menus.** Alt+Down on a cell lists the values already in its column to pick from (Excel's "Pick from drop-down list"). Double-clicking the edge of the selection jumps that way like Ctrl+arrow. Right-click menus say how many ("Insert 3 rows above", "Delete rows 5–7"), and the cell menu has Edit cell, Pick from a list, Note and flag, Hide, Show my edits and List of my changes; the column menu has Set column width… and Column summary. With the filter buttons off, pointing at a heading shows an arrow for the column's menu. Pointing at a link shows its address. Dragging the fill handle back inside the selection clears those cells. View › List arrows on every cell shows the pick-list arrow on each cell of a column with a list.

**File tabs.** Right-click a tab for Save, Rename, Copy path, Show in File Explorer, Close other tabs, Close tabs to the right and more. Double-click the empty tab bar for a new file; Ctrl+Shift+T opens the last closed file again.

**Smaller things.** Find and Replace start on "Selection" when several cells are selected. File › Options › Editing chooses where Enter moves (down, right, up, left or stay). Enter in the cell bar puts the value in and moves down. Ctrl+Shift+0 shows only the hidden columns inside the selection (Unhide all columns shows every one). Set column width… types an exact width, and AutoFit also measures the first and last 2,000 rows of the file. Every dialog answers Enter with its main button. Enter in the name box no longer starts editing the cell it went to.

**Not added, on purpose.** Freezing rows or columns is not an undo step (it isn't in Excel either). Sorting always moves whole rows (no "sort just this range"), which is the safe choice for CSV files. There is no filter by colour, no right-drag fill menu or fill options button, and no End-key mode (End goes to the last column, as in Google Sheets). Notes belong to rows, not single cells. Say if you want any of these.

## Install

1. Download `Natendo.Data.Edit_0.3.5_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
