## What's new in 0.4.3

**Explore a file fast.** Four ways to see what a file holds before you change anything:

- **Counts tab** (Data › Count values in a new tab, Alt+Shift+F, or right-click a heading). Every value of a column, or of several columns together, with its count and percent, most common first, in a tab of its own you can sort, filter and save. Double-click a line, or press Enter, to show its rows in the original tab.
- **Column profile** (Data › Column profile, or right-click a heading). The shapes of a column's values (`99999` 98%, `99999-9999` 1.5%), a small chart of its numbers, dates or lengths, the shortest and longest values, and the odd ones: rare shapes and numbers far from the rest. Click any line to show its rows.
- **Filter panel** (View › Filter panel, Alt+Shift+L). A card per column with each value and its count, or a chart of numbers or dates you can drag across. The counts follow your picks, like a shop's search filters, and every pick is an ordinary filter, so Undo and Clear filter work as usual.
- **Column insights** (View › Column insights, off until you switch it on). A thin strip under each heading: how full the column is, how many different values it holds and a tiny chart. On a big file it reads a sample from the start, middle and end, so it never slows anything down. Click a strip for the column profile.

Every one of them was timed on a 10-million-row file: a counts tab in 0.12 s, a column profile in 0.35 s, the filter panel's counts in 0.16 s and the insight strip in 0.33 s.

## Install

1. Download `Natendo.Data.Edit_0.4.3_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
