## What's new in 0.2.1

**A new, original app icon.** Natendo Data Edit now has its own icon: a teal tile holding a grid of cells, with the selected cell in gold. You'll see it in the taskbar, the Start menu, the title bar, the installer and the menu bar inside the app.

- The tiny 16, 20 and 24 pixel sizes are drawn by hand, pixel by pixel, so the icon stays sharp in the taskbar and title bar instead of going blurry.
- The Windows icon now includes the 20 and 40 pixel sizes, so it also looks crisp at 125% and 250% display scaling.

There are no other changes to how the app works since 0.2.0.

## Install

1. Download `Natendo.Data.Edit_0.2.1_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Windows may keep showing the old icon on existing shortcuts for a little while, because it caches icons. Signing out and back in, or restarting, clears that.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
