## What's new in 0.4.0

**Find & Replace, part three.** The last part of the Find & Replace rework:

- **Numbers by value.** Pick "Numbers by value" and `5` finds 5, 5.00 and $5 (but not 15). Ranges and comparisons work too: `10..20`, `>5`, `>=5`, `<5`, `<=100`.
- **Dates by value.** "Dates by value" finds `1/5/2024` however the date is written (2024-01-05, Jan 5 2024, with or without a time). Ranges and comparisons work the same way: `1/1/2024..3/31/2024`, `>1/5/2024`.
- **Similar spelling.** "Similar spelling" finds whole cells a letter or two apart, ignoring case, accents and punctuation: "Jon Smyth" finds "John Smith".
- For these three, Replace puts the replacement in the whole cell.
- **Preserve case.** Tick Preserve case next to Replace and "smith" → "jones" turns SMITH into JONES and Smith into Jones.
- **Include hidden now covers hidden rows too.** Rows a filter or you hid are counted, listed (marked "hidden") and replaced, and the Replace all preview says how many of the changed cells are hidden. Find next and the lit-up matches stay on the rows you can see.
- **By columns.** Find next can go down each column before moving right, as in Excel.
- **Copy list.** Find all's list of matches can be copied as tab-separated text (row, column, cell), after the usual privacy check.
- **Saved searches.** Saved ▾ keeps a search, its replacement and its options under a name on this computer, until you delete it.

## Install

1. Download `Natendo.Data.Edit_0.4.0_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
