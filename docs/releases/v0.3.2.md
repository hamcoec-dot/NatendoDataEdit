## What's new in 0.3.2

**Rename a column.** Double-click a column heading, right-click it and choose Rename column, or use Format > Rename column. The new name goes in the header row as one undo step. A file without a header row gets one, and the other columns keep their numbers as names. Right-clicking a heading, row number or cell outside the selection now selects it first, so the menu acts on what you clicked.

**Smoother tab dragging.** Dragging a file tab no longer selects text on the tab bar. The tab you drag follows the pointer, and the tabs it passes slide aside to open a gap where it will land, so you can always see where it is going. It moves when you let go and becomes the tab shown; press Esc before letting go to leave the tabs as they were. Ctrl+Shift+PageUp and Ctrl+Shift+PageDown move the shown tab left or right from the keyboard.

Everything from 0.3.1 is included: File > Open recent (Ctrl+Shift+O) with middle-click to open each file in a new tab, and same-named files told apart by their folder.

## Install

1. Download `Natendo.Data.Edit_0.3.2_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
