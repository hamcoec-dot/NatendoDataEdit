## What's new in 0.4.8

- **The title-row question gets out of the way.** The question about whether the first row holds the column names now floats in a small box over the bottom of the table instead of a bar above it. Once you answer it (or flip the switch, or close it), it fades away and nothing is left behind, and the table never moves when it comes or goes.
- **Copy column names.** Edit > Copy column names (also on the heading and corner right-click menus) copies all the names of the shown columns, or of the columns selected, as one row ready to paste into a spreadsheet or another tab; "as a line of text" uses the file's own delimiter. Copy with column names (Ctrl+Shift+C) copies the selection with the names on top. Paste as column names turns copied names, a row or a list, into the title row of the file open, as one undo step.

## Install

1. Download `Natendo.Data.Edit_0.4.8_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
