## What's new in 0.4.6

- **A file remembers its title row.** When you tell the app that a file's first row holds the column names (or that it doesn't), it remembers. Open the file again, from Open, Recent files or Windows, and the choice is the same as when you closed or saved it. A title row added and then closed with Don't save is not kept. Only a salted fingerprint of the file's path and the choice are kept, on this PC, for the 1,000 files used last; nothing is kept for files in private mode. Format › Forget this file's title-row choice (also on the tab's right-click menu) or Forget remembered title rows clears them.

Opening a file costs nothing extra you can notice: looking up the choice takes well under a millisecond.

## Install

1. Download `Natendo.Data.Edit_0.4.6_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
