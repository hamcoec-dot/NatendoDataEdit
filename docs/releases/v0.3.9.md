## What's new in 0.3.9

**Find & Replace, part two.** The find bar (Ctrl+F, Ctrl+H) can do a lot more:

- **Find blank cells.** Pick "Blank cells" in the pattern box to find, count or fill the empty cells.
- **Special…** puts in characters that are hard to type or to see: a non-breaking space, a zero-width space, a tab, a line break, curly quotes, and in a regular expression any digit or any letter.
- **Column titles.** Tick "Column titles" to search the first row too. Replacing there renames the column, so views and data checks follow the new name.
- **Row notes.** Set "In row notes" to search the notes on rows.
- **Pick columns by name.** Search in "Columns…" opens a list of the columns (Select all, Unselect all) so you can search just "Last name" and "Street" without selecting them.
- **All open tabs.** Find all lists the matches in every open file, each with its tab; click one to go there. Replace all shows each tab's part first, then changes them, one undo step per tab.
- **Act on the rows Find all found:** show only those rows, copy them to a new tab, flag them with a coloured flag, or delete them (it asks first; Ctrl+Z puts them back).
- **Untick changes** in the Replace all preview to leave those cells as they are. After Replace all, **Show changed rows** shows only the rows it changed.
- **Change case in a replacement.** In a regular expression's replacement, `\U$1` and `\L$1` make upper or lower case until `\E`, and `\u$1` makes just the first letter a capital ("smith" becomes "Smith").
- **The status bar** says "Find: 1,204" while the find bar is open.
- **The single Replace button** is no longer saved as a step in recorded recipes; Replace all still is.

**Replace from a list** (Find › Replace from a list…, or "From a list…" in the find bar): paste two columns, what to find and what to put instead, or take them from two columns of another open tab, up to 100,000 pairs. Choose whole cells only (fast, for codes such as TN → Tennessee) or text inside cells, where the longest match wins. Every pair applies at once, so "A to B" and "B to C" never chain. You see what changes before anything does, and it is one Ctrl+Z.

## Install

1. Download `Natendo.Data.Edit_0.3.9_x64-setup.exe` below.
2. Run it. It installs for your Windows account only and does not need administrator rights. If an older version is installed, close the app first; setup installs over it.

The installer is not code-signed yet, so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11.

This installer was built by GitHub Actions straight from the code in this repository.
